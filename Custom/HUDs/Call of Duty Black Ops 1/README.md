## Installation
1) Go to `zone_source\all\assetlist` in bo3 root.

2) Open this file:
`core_post_gfx.csv`

3) Find this line:
`fonticon,fonticon/weapons.csv`

4) Add `//` in front of it. Like this:
`//fonticon,fonticon/weapons.csv`

5) Save the file.

6) Drop the `_custom` & `bin` folders into bo3 root, If prompted overwrite the existing file(s).

7) Place the contents of `your_maps_folder` into your map's folder

8) In GSC & CSC:
`#using scripts\zm\_zm_t5_hud;`

9) In your zone file:
`include,t5_hud`

10) That's it, please credit me if you use it.
